# Autoencoders on MNIST: Denoising and Image Generation

Three autoencoder architectures implemented from scratch in **PyTorch** on MNIST:
a standard **autoencoder (AE)**, a **denoising autoencoder (DAE)** and a **variational autoencoder (VAE)**.

Project for the **Advanced Machine Learning** module, M.Sc. Data Science, Justus-Liebig-Universität Gießen.

## Key Result

A standard autoencoder reconstructs clean digits almost perfectly, but **fails on noisy inputs**.
Training the same architecture as a denoising autoencoder **reduces the reconstruction error on noisy images by 4×**.

| Model        | Input                   | Mean MSE (10,000 test images) |
|--------------|-------------------------|------------------------------:|
| AE           | clean                   | 0.00181 |
| AE           | noisy (Gaussian, σ=0.5) | 0.04662 |
| Denoising AE | noisy (Gaussian, σ=0.5) | **0.01155** |

All models are evaluated on the full MNIST test set. The AE and the DAE see exactly the same noisy images (fixed seed).

## 1. Autoencoder

**Architecture:** 784 → 512 → 256 → 512 → 784 (fully connected, ReLU, sigmoid output), trained with MSE loss.


**Robustness test:** the trained AE is fed images corrupted with Gaussian noise. It reproduces the noise
instead of removing it, and the error increases by about 25×.


## 2. Denoising Autoencoder

Same architecture, but trained with **noisy inputs and clean targets**:

```
x (clean) → + noise → x_noisy → Encoder → z → Decoder → x_hat
loss = MSE(x_hat, x)
```

Because the target is the clean image, the model has to learn to remove the noise instead of copying it.


## 3. Variational Autoencoder

The VAE learns a probabilistic latent space (50 dimensions):
- the encoder outputs a mean μ and a log-variance log σ²
- **reparameterization trick**: z = μ + σ · ε, with ε ~ N(0, I)
- loss = reconstruction loss (MSE) + **KL divergence** to the prior N(0, I)
